HOW TO USE

Type a slash. Get a focused answer.

Start typing a command in an approved Discord server, complete the required options, and submit it. Results are returned as readable messages and embeds.

/vstats cid:<CID>

Display public VATSIM and VATUSA member information.

/metar icao:<ICAO>

Retrieve the latest airport METAR.

/taf icao:<ICAO>

Retrieve the latest airport TAF.

/datis icao:<ICAO>

Display available FAA Digital ATIS.

/hndconfig

Show the current official Haneda runway configuration.

/hndschedule

Show the current Haneda operating period in Japan time.

/arrtransalt icao:<ICAO> fix:<FIX>

Find arrival and approach transfer information for a route FIX.

/deptransalt icao:<ICAO> fix:<FIX>

Find departure and climb transfer information for a route FIX.

/jpnroute

Open the JPN Route website directly from Discord.
