COMMANDS

Type a slash, get an answer

In an approved server, type / , pick a command and fill in the options. Results come back as clean, readable embeds.

/vstats cid:<CID>

Public VATSIM and VATUSA profile for a CID.

/metar icao:<ICAO>

Latest METAR for an airport.

/taf icao:<ICAO>

Latest TAF for an airport.

/datis icao:<ICAO>

FAA Digital ATIS, where available.

/hndconfig

Haneda's current official runway configuration.

/hnddep sid:<SID>

The SID version and departure runway in use right now, based on Japan time and the runway configuration.

/hndarr entry:<FIX>

Arrival runway, STAR and approach for a Haneda entry fix.

/arrtransalt icao:<ICAO> fix:<FIX>

Arrival and approach transfer details for a route fix.

/deptransalt icao:<ICAO> fix:<FIX>

Departure and climb transfer details for a route fix.

/jpnroute

Open the JPN Route website.

ACCESS

By approval only, no public invite

To use Jurina's Bot in your server, send an email with the server name, what it's for, how you plan to use the bot and roughly how many members it has.

Approval is at the operator's discretion and can be withdrawn if the bot is spammed, automated, used for bulk collection, or used against Discord's or a data provider's rules.

Request access by email dev@jurina.org

RESPONSIBLE USE

Use it with care

No scraping or abuse

Don't spam commands, automate lookups, enumerate CIDs or build archives, and never use results to harass, track or impersonate anyone.

Respect provider rules

Follow Discord's rules and the policies of VATSIM, VATUSA, aviationweather.gov, atis.info and every other data source the bot cites.

Simulation only

All aviation, weather, ATIS, runway, timing and transfer data is for flight simulation and community reference only.
